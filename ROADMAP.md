# Roadmap

## Vision

The easiest way for any developer to understand and improve how their GitHub profile looks to
recruiters and the open-source community.

## Milestones

### Now

- [ ] Publish to PyPI so `pip install gh-profile-stats` works
- [ ] Authenticate with `GITHUB_TOKEN` when the GitHub CLI is not installed
- [ ] Paginate repositories so stars are counted for accounts with more than 100 repos

### Next

- [ ] A GitHub Action that posts your rank to the profile README on a schedule
- [ ] Contribution streaks and language breakdown
- [ ] Compare two profiles side by side
- [ ] Optional rank labels matching github-readme-stats

### Later

- [ ] A hosted SVG badge service (`/api/rank?username=...`)
- [ ] Team and organisation reports
- [ ] A web UI with history over time

## Where this can go

| Direction       | Idea |
| --------------- | ---- |
| **Startup**     | Developer-branding analytics: profile audits and career-readiness reports for students and bootcamp graduates. |
| **Publication** | Study of which GitHub signals (reviews, stars, topics) correlate with open-source adoption. |
| **Open source** | A small, dependency-free library other tools can import. |
